# Banking Credit Risk Intelligence

End-to-end credit risk analytics project for a fictional retail bank: which customer segments carry more credit risk, how repayment behaviour changes over time, and which customers are likely to default next month.

**Stack:** Python · SQL Server · Power BI / DAX · scikit-learn

## Status

- [x] Milestone 1: environment, data download, data-quality checks
- [x] Milestone 2: SQL Server schema and analytics views
- [ ] Milestone 3: Power BI report
- [ ] Milestone 4: default prediction model
- [ ] Milestone 5: management summary

## Data

[UCI Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients): 30,000 Taiwanese credit card customers, April–September 2005, with default status for October 2005 (22.1% default rate).

Limitations: it's historical (2005), Taiwanese rather than Dutch, and has no recovery, profitability or full cash-flow data. `LIMIT_BAL` is a credit limit, not exposure at default. This project is a technical demonstration, not a lending model.

See [docs/data_dictionary.md](docs/data_dictionary.md) for variables and data-quality findings.

## Reproduce

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

python src/load_data.py       # downloads to data/raw/
python src/validate_data.py   # quality report + data/processed/credit_default_validated.csv
```

Then build the database (SQL Server Express, instance `SQLEXPRESS`):

```powershell
$server = 'np:\.\pipe\MSSQL$SQLEXPRESS\sql\query'   # local named pipe for SQL Express
sqlcmd -S $server -E -C -i sql\01_create_tables.sql
python src/load_to_sql.py
sqlcmd -S $server -E -C -i sql\02_load_data.sql        # ends with reconciliation checks
sqlcmd -S $server -E -C -i sql\03_analytics_views.sql
```
